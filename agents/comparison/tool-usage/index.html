工具系统设计差异：
CC 最"重"——13+ 内置工具、MCP、Skill、Plugin、流式执行，功能最全面。
CX 最"安全"——工具经过 ToolOrchestrator + Guardian + Sandbox 三重防护。
OX 最"灵活"——双层注册(Location + Process) + Effect Schema 验证 + 权限过滤，适合插件化。
