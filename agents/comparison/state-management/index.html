状态恢复对比

维度CCCXOX
恢复方式 读取 JSONL → 反序列化 → restoreSessionStateFromLog() ThreadStore.load_history() → 重建上下文 SQL 查询 + Context Epoch 比对 → delta 恢复
恢复粒度 全量（读所有 JSONL 行） 全量或分页（ThreadHistoryMode） 按需（从最新 compaction 点开始）
增量更新 无（每次重建） AdditionalContextStore.merge() — 只发变化的 SystemContext.reconcile() — 只发 delta
关键差异：CX 最"重"（4个 SQLite DB），CC 最"轻"（JSONL 文件），OX 最"结构化"（事件溯源+投影）。CX 的 Rust Mutex 保证线程安全但增加复杂度，OX 的 Effect 依赖注入天然支持测试和替换。
