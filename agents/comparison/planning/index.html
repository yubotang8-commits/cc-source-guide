推理策略对比

维度CCCXOX
默认策略 隐式 ReAct（LLM 自主选择工具） 隐式 ReAct + 可选 update_plan checklist 隐式 ReAct + 可选 TodoWrite
显式规划 Plan Mode（工具级开关） ModeKind::Plan + CodeMode Plan Agent（代理级隔离）
代码执行模式 — Code Mode: LLM 写 JS 代码单元
代码可调用嵌套工具		 —
步骤限制 maxTurns 参数 — agent.steps → MAX_STEPS_PROMPT
工具禁用 + 强制文本回复
设计哲学差异：
CC 最"显式"——Plan Mode 是独立权限模式，有专门的 Plan 子代理，Plan 文件跨会话持久化。
CX 最"灵活"——ModeKind 枚举支持多种模式，Code Mode 允许 LLM 编写可执行代码。
OX 最"简单"——Plan 就是另一个 Agent，通过权限 deny 实现只读，无独立模式切换机制。
