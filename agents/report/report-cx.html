2.2 Turn 循环 — run_turn()

run_turn(): loop { ① 从 input_queue 获取待处理输入 ② 运行 hooks_and_record_inputs → 若 hooks 阻止则 break ③ 构建 StepContext（工具/MCP 快照） ④ run_sampling_request() → 流式调用模型 + 执行工具 ⑤ 检查 token 预算 → 是否需要 auto-compact ⑥ should_roll_over = needs_follow_up && (new_context_window || token_limit) ├─ roll_over → 开始新的上下文窗口 └─ auto_compact → 压缩历史 ⑦ 运行 turn-stop hooks }

4. 记忆机制

4.1 两阶段记忆管线

启动时: Phase 1: 从历史 Rollouts 提取记忆 → 从 state_db 认领待处理 rollout → 加载 rollout items → AI 提取 → { raw_memory, rollout_summary } → 存入 memories DB ↓ Phase 2: 合并原始记忆 → 获取全局 Phase 2 锁 → 准备 git 仓库作为记忆工作区 → 启动受限 agent 合并记忆 → agent 配置: 无网络、无 MCP、临时、不递归 → 结果写入 $CODEX_HOME/memories/MEMORY.md

7.4 Shell 安全分类

// 安全命令白名单
is_safe_to_call_with_exec():
  "cat" | "ls" | "grep" | "head" | "tail" | "wc" | ... → true
  "git" → 仅子命令: status, log, diff, show, branch (只读)
  "find" → 仅无 -exec/-delete
  "sed" → 仅 -n {N|M,N}p

// 危险检测: 递归解析 bash -lc "..." 中的嵌套命令
dangerous_command_match():
  "rm -f" → ForcedRm
  "sudo ..." → 递归检查
  "trap ..." → 检查嵌套危险命令
