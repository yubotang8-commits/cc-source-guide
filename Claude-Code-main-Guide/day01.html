Day 01 - CC 是什么 & 整体架构鸟瞰

CC 是什么

Claude Code（CC）是一个运行在终端里的 AI 编程助手。你在命令行里打字，它帮你写代码、改 bug、操作文件。它本质上是一个"对话循环"：

你输入文字 → CC 把文字组装成消息 → 发给大模型 → 大模型回复 → CC 展示结果 ↑ | └────────────── 如果大模型要用工具，执行后继续发 ─────────────┘

六大核心模块

把 CC 想象成一家餐厅，6 个模块就是 6 个岗位：

模块餐厅比喻源码位置
输入处理服务员接单src/utils/processUserInput/
提示词管理厨师看菜谱src/utils/systemPrompt.ts, context.ts
消息管理传菜员递盘子src/utils/messages.ts, src/services/compact/
大模型调用后厨做菜src/services/api/claude.ts
工具/技能/MCP厨房设备src/tools/, src/skills/, src/services/mcp/
状态管理账本记录src/state/, src/bootstrap/state.ts

整体架构图

┌─────────────────────────────────────────────────────┐ │ 用户终端 (Terminal) │ │ ↕ 键盘输入 / 屏幕输出 │ ├─────────────────────────────────────────────────────┤ │ REPL 界面层 │ │ (src/screens/REPL.tsx) │ ├──────────┬──────────┬──────────┬────────────────────┤ │ 输入处理 │ 提示词 │ 消息管理 │ 状态管理 │ │ process │ system │ messages │ store │ │ UserInput │ Prompt │ compact │ AppState │ ├──────────┴──────────┴──────────┴────────────────────┤ │ QueryEngine (查询引擎) │ │ (src/QueryEngine.ts) │ ├─────────────────────────────────────────────────────┤ │ 大模型 API 调用层 │ │ (src/services/api/claude.ts) │ ├──────────┬──────────┬───────────────────────────────┤ │ 工具执行 │ 技能系统 │ MCP 协议 │ │ tools/ │ skills/ │ services/mcp/ │ └──────────┴──────────┴───────────────────────────────┘

一个请求的简短旅程

1. 你在终端打字："帮我写个排序函数" 2. REPL 组件捕获输入 3. processUserInput() 处理成 UserMessage 4. QueryEngine 拿到消息，组装系统提示词 + 历史消息 5. 调用大模型 API（流式请求） 6. 大模型返回文字，也可能要求调用工具 7. 如果要调工具 → 执行工具 → 把结果加到消息 → 回到步骤 5 8. 大模型说"说完了" → 结果显示在终端
今天的目标只是建立大局观，不需要记住每个细节。后面每天会深入一个模块。
