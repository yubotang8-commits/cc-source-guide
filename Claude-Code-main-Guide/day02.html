Day 02 - 源码目录结构一览

顶层目录

Claude-Code-main/ ├── src/ ← 所有源码都在这里 ├── package.json ← 项目配置、启动命令 ├── tsconfig.json ← TypeScript 编译配置 └── docs/ ← 文档

src/ 下的核心目录

src/ ├── main.tsx ← 主入口（约2000行） ├── query.ts ← 核心查询循环（最大文件） ├── QueryEngine.ts ← 查询引擎（给 SDK 用） ├── tools.ts ← 工具注册表 ├── Tool.ts ← 工具类型定义 ├── commands.ts ← 命令注册表 ├── context.ts ← 上下文获取 │ ├── bootstrap/ ← 启动阶段的全局状态 │ └── state.ts │ ├── state/ ← 状态管理系统 │ ├── store.ts ← 轻量 createStore 实现 │ ├── AppState.tsx ← React 状态组件 │ └── AppStateStore.ts ← 状态类型定义 │ ├── services/ ← 核心服务 │ ├── api/ ← 大模型 API 调用 │ ├── compact/ ← 上下文压缩 │ ├── mcp/ ← MCP 协议管理 │ └── analytics/ ← 数据统计 │ ├── tools/ ← 各个工具实现 │ ├── BashTool/ │ ├── FileReadTool/ │ ├── FileWriteTool/ │ ├── AgentTool/ │ ├── MCPTool/ │ └── ... │ ├── hooks/ ← React hooks（60+个） │ ├── components/ ← UI 组件 │ ├── screens/ ← 页面 │ └── REPL.tsx ← 主界面 │ ├── commands/ ← 斜杠命令 │ ├── commit/ │ ├── config/ │ └── ... │ ├── memdir/ ← 记忆系统 │ ├── memdir.ts │ ├── memoryTypes.ts │ └── findRelevantMemories.ts │ ├── skills/ ← 技能系统 │ ├── loadSkillsDir.ts │ └── bundled/ │ └── utils/ ← 工具函数 ├── messages.ts ← 消息创建/转换 └── processUserInput/ ← 输入处理

按功能归类

功能关键文件一句话说明
启动main.tsx, bootstrap/state.ts程序从这里开始跑
输入utils/processUserInput/把你的键盘输入变成程序数据
查询query.ts, QueryEngine.ts组织消息、调大模型、处理回复
提示词utils/systemPrompt.ts, context.ts拼装给大模型的"说明书"
消息utils/messages.ts, services/compact/消息的创建、格式转换、压缩
工具tools/, tools.ts读写文件、执行命令等能力
记忆memdir/跨会话记住你的偏好
技能skills/可扩展的命令/流程模板
MCPservices/mcp/连接外部工具服务
状态state/, bootstrap/state.ts全局共享的数据
APIservices/api/和大模型通信的网络层
