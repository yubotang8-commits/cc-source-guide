Day 06 - 用户输入捕获：从键盘按键到程序数据

输入的完整路径

你的键盘 │ 按下 "h" "e" "l" "l" "o" Enter ▼ Ink 的 useInput hook（监听终端按键） │ ▼ PromptInput 组件（管理输入框状态） │ 拼接字符、处理退格、回车提交 ▼ useTextInput hook（封装输入逻辑） │ ▼ onSubmit 回调触发 │ 拿到完整字符串 "hello" ▼ processUserInput() 函数 │ 进入下一课的内容……

useInput：终端里的"键盘监听器"

Ink 提供的 useInput 可以捕获终端里每一个按键：

useInput((input, key) => { // input = 按下的字符，比如 "a" // key = 特殊键状态，比如 key.enter、key.backspace、key.tab if (key.enter) { // 用户按了回车，提交输入 } if (key.backspace) { // 用户按了退格，删除最后一个字符 } if (key.tab) { // 用户按了 Tab，触发自动补全 } })

PromptInput 的状态

输入框需要记住几个东西：

状态说明例子
value当前输入的文字"帮我写个"
mode输入模式普通模式 / 多行模式
cursorPosition光标在哪第4个字符后面
history历史输入记录["上次输入1", "上次输入2"]

特殊输入方式

不只是打字，还有这些输入方式： 1. 普通打字 → "帮我写个函数" 2. 斜杠命令 → "/commit" → 走命令处理路径 3. 粘贴内容 → 可以粘贴多行文本 4. 粘贴图片 → 图片会被转成 base64 编码 5. IDE 拖拽选择 → 从编辑器拖代码片段进来 6. 上下箭头 → 翻历史输入记录
输入捕获是"你说话"的第一步。从按键到字符串，CC 用 Ink 的 useInput + 自定义的 PromptInput 组件完成这个过程。
