10天 Agent 面试突击：以 Claude Code 源码为范本

本课程基于网络面经高频考点，结合 Claude Code（CC）源码的最佳实践，帮你拿下 Agent 方向面试。难度定位：中高级（已完成30天基础走读）。

课程设计理念

面经调研 → 提炼高频考点 → 对照 CC 源码实践 → 给出面试级回答 每个知识点包含： 面试题（原题 + 公司标签 + 难度） 参考回答（面试官想听什么） 常见误区（大多数人踩的坑） CC 源码实践（工业级怎么做的） 深入追问（面试官的 follow-up）

高频考点地图

Agent 面试五大维度（几乎每场必考）： 1. 架构设计 → Day 01-02 三层架构、ReAct 实现、循环终止、熔断机制 2. 提示词工程 → Day 03-04 三字段协作、分段缓存、CLAUDE.md 注入、近因效应 3. 工具系统 → Day 05-06 并发安全、权限控制、MCP 降级、技能注册 4. 上下文管理 → Day 07-08 5层压缩、墓碑消息、熔断、记忆 vs 压缩 5. 流式与协议 → Day 09-10 SSE 流式、参数完整性、两层重试、系统设计终局

与30天走读的关系

30天走读教的是"CC 怎么实现"（读源码），本课程教的是"面试怎么答"（输出能力）。

同一条知识，走读侧重"代码在哪里、怎么跑"，面试侧重"为什么这么设计、有什么取舍、跟其他方案比如何"。

建议：每篇先自己试着答面试题，再对照参考回答看差距。
